# Project Mentor — Brainstorm to Build Anything

**Turn a rough idea into a finishable, agent-ready project.**

Project Mentor is an honest, one-question-at-a-time design mentor that helps you go from a vague brainstorm to a clear, approved log and inheritance document that any AI or agent can use to build. It works for software, full-stack apps, system design, simple programs, businesses, skills, books, games, art, research, and more.

## Why use it

- **Honest pressure** — Surfaces contradictions, gaps, unrealistic scope, and real-world conflicts with a recommended fix. You decide.
- **Approved-only log** — Nothing becomes binding until you explicitly approve it. Status markers (Open / Approved / Parked / N/A) keep agents from guessing.
- **Reverse flowchart** — Starts from your goal and works backward to the first missing prerequisites so you always know what to do next.
- **Agent-ready handoff** — Produces a Director brief and modular structure so one agent (or many) can pick up a slice and execute without guessing.
- **Works for light brainstorms or large projects** — Load-when-needed sections keep simple sessions fast while full capability stays available for systems, full-stack, business, and skill work.
- **Portable** — Plain text. Works in any AI. No required tools or dependencies.

## What it can do

- Settle purpose and success criteria, then grow modules, decision trees, and forward/reverse charts.
- Handle starter materials (docs, images, links, videos, audio, notes) without bloating the log.
- Design system architecture, full-stack apps, simple programs, and business offers with concrete acceptance criteria.
- Produce an inheritance document + log that a director agent can turn into prompts for other agents.
- Optionally build and test a reusable AI skill, then plan publishing.
- Audit for contradictions, blocking gaps, and severity risks before handoff.

## How to use

1. Drop the skill into your AI (Claude, Grok, Cursor, or any host that supports custom instructions or skills).
2. Say something like “Mentor me on this project” or “Help me think this through.”
3. Answer one high-leverage question at a time.
4. Approve what you want locked in.
5. When finishable, ask for an audit or package. You get a clean inheritance document ready for agents or teammates.
