# Project Mentor — Brainstorm to Build Anything

Honest, one-question-at-a-time design mentor that turns a rough idea into an approved, agent-ready project log and inheritance document. Works for software, systems, businesses, skills, books, and more.

## Install (standalone)
1. Open [`SKILL.md`](SKILL.md).  
2. Copy the entire file.  
3. Paste into your AI as a system prompt, custom instructions, project knowledge, or skill file (Claude Projects, Cursor, Grok, etc.).

## Why use it
- Surfaces contradictions, gaps, and unrealistic scope with a recommended fix. You decide.  
- Nothing becomes binding until you explicitly approve it.  
- Reverse flowchart starts from your goal and works backward to the next missing prerequisite.  
- Produces a clean inheritance document any agent can pick up without guessing.

## How to use
1. Load the skill.  
2. Say something like “Mentor me on this project.”  
3. Answer one high-leverage question at a time.  
4. Approve what you want locked in.  
5. Ask for an audit or package when finishable.
